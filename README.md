# GEMAYA - mises a jour

Depot public de distribution. Il ne contient que l'APK de mise a jour et le
fichier `update.json` que l'application lit pour se mettre a jour.

L'APK publie ici ne contient pas la cle de lecture de plaque : elle se saisit
une fois dans l'application (Configuration > Intelligence artificielle).

Le code source vit dans un depot prive separe.
